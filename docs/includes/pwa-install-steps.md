=== "Android (Chrome)"

1. Open [the companion]({{ companion_url }}/) in **Chrome**.
2. Tap the **⋮** menu → **Install app** or **Add to Home screen** (wording varies by version).
   Or accept the in-app **Install** banner on the Wallets page if shown.
3. Confirm **Install**.

=== "iPhone / iPad (Chrome or Firefox)"

1. Install Chrome or Firefox from the App Store if needed.
2. Open [the companion]({{ companion_url }}/) in that browser.
3. Use the browser’s **Share** / menu → **Add to Home Screen** (label varies).
4. Confirm the name **PiWalletSV** → **Add**.

=== "iPhone / iPad (Safari)"

1. Open [the companion]({{ companion_url }}/) in Safari.
2. Tap **Share** (square with ↑).
3. Scroll and tap **Add to Home Screen**.
4. Confirm the name **PiWalletSV** → **Add**.

=== "Desktop Chrome / Edge"

Optional — mainly for development. Use the install icon in the address bar
(⊕ or computer icon) after visiting the companion over HTTPS.
